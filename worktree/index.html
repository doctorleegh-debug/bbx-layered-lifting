    언어검토 체크는 담당자 확인 표시입니다(수정 문구 1건 이상). 전체 번역 승인·업로드와는 별개입니다.

    언어검토와 업로드는 서로 독립된 체크입니다. ‘?’는 확인 기록이 없는 상태입니다. ‘전국가’는 각 박스에 표시된 대상 국가 기준입니다. 오래된 상태는 박스의 기록 날짜를 확인해 주세요. 홈페이지 체크는 다른 PC에도 자동 반영됩니다. 메모·링크는 브라우저별로 보관되며 백업으로 옮길 수 있습니다. 기존 브라우저의 체크는 첫 접속 시 자동 합쳐집니다. Ctrl+Z 또는 실행 취소 버튼으로 이 화면에서 변경한 최근 30건을 되돌릴 수 있습니다. 새로고침하거나 백업을 가져오면 실행 취소 기록은 초기화됩니다. 입력 중인 글자는 기본 글자 취소가 적용됩니다.
